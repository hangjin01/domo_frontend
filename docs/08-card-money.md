# 카드 금액과 날짜별 금액표

## 사용법

카드를 새로 만들거나 더블클릭하면 상세 창이 열립니다. 설명 아래 **금액 옵션 · 원화**에서 사용 안 함 / + 금액 / − 금액 / 총합 / 평균을 선택하고 저장합니다. 금액은 0 이상의 정수 원 단위입니다. 날짜는 일정과 독립적인 기준 날짜이며 기본값은 컴퓨터의 오늘 날짜입니다.

연결을 시작한 카드에서 도착 카드 방향으로 계산합니다. 실선/점선/화살표의 외형은 계산에 영향을 주지 않습니다. 총합과 평균은 들어오는 모든 경로를 역탐색하고 원본 +/− 카드만 한 번씩 사용합니다. 중간 합계 카드는 재합산하지 않습니다. 금액 없는 중간 카드도 연결 경로로 사용합니다. 순환 연결은 오류, 입력 원본이 없으면 ‘계산 대상 없음’입니다. 평균은 음수 포함 원본 금액의 산술평균이며 표시만 소수 둘째 자리까지 반올림합니다.

왼쪽 **금액표**에서 시작일과 종료일(양 끝 포함), 계산 카드 필터를 지정할 수 있습니다. 상세 내역의 카드명을 누르면 편집창이 열립니다. 날짜별 합계는 원본 기준 날짜로 계산하고, 아래의 계산 카드 결과는 날짜 필터와 무관한 전체 연결 결과라고 명시합니다.

## Excel

‘엑셀 내보내기 (.xlsx)’는 날짜별 집계, 상세 내역, 계산 카드 세 시트를 만듭니다. 첫 두 시트는 화면 필터를 따르고 계산 카드 시트는 전체 연결 기준의 스냅샷입니다. 날짜/금액은 Excel 숫자형으로, 카드 제목/설명은 수식이 아닌 문자열로 저장합니다. 원본 카드 내용이 `=`로 시작해도 실행되지 않습니다. 서버 업로드나 외부 라이브러리 다운로드 없이 동작합니다. 파일을 다시 가져오는 기능은 없습니다.

## 데이터와 구현

- `Task.money`: `{ mode, amount, date } | null`. 기존 카드에는 필드가 없어 기본적으로 꺼져 있습니다.
- 계산 결과는 저장하지 않고 카드/연결 변경 시 재계산합니다. 원본 금액은 기존 로컬 보드와 백업에 함께 보존됩니다.
- `models/utils/money.ts`: 검증, 중복 제거 역방향 탐색, 순환 감지, 날짜 필터.
- `views/task/MoneyFields.tsx`: 금액 입력과 카드 결과, 계산 원본 목록.
- `views/board/MoneyView.tsx`: 기간별 내역 및 집계, 내보내기.
- `lib/moneyExcel.ts`: 최소 OOXML과 CRC32 ZIP 생성. 수식 없는 결과 파일.
- 현재 로컬 데모/데스크톱 저장 모드에서 지원합니다. 실제 원격 백엔드 스키마와 마이그레이션은 추가하지 않았으며 원격 모드에서 금액을 저장하려 하면 명시적으로 실패합니다.

이번 개발부터는 기능 구현과 테스트를 모두 끝낸 뒤 마지막에 Linux AppImage를 빌드합니다. 기존 실행 앱과 사용자 데이터 경로는 유지합니다.
