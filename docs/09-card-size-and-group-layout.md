# 카드 크기와 그룹 정렬

- 카드 오른쪽 아래 ◢ 핸들을 드래그하면 크기를 바꿉니다. 카드 이동/연결 이벤트와 분리되어 있습니다.
- 카드 상세의 ‘카드 크기’에서 너비 220~800px, 높이 100~800px를 저장할 수 있습니다. 기본 크기는 280×140px입니다.
- 기존 카드의 내용·금액·연결은 보존하며 `Task.width/height`만 추가 저장합니다. 현재 로컬 저장 모드 지원입니다.
- 그룹의 슬롯은 해당 그룹에서 가장 큰 카드의 크기를 기준으로 계산합니다. 왼쪽 패딩 20px, 헤더 포함 첫 행 70px, 행 간격 12px를 공통 적용합니다.
- 기존 저장 좌표는 순서를 결정하는 데 사용하고 실제 표시 좌표는 공통 슬롯에서 계산합니다. 다음 드롭 시 정렬된 상대 좌표를 저장합니다. 그룹 제거 시에도 실제 표시 위치를 유지합니다.
- 렌더링, 드롭 미리보기, 드롭 저장, 그룹 영역, 카드 크기가 서로 다른 값을 쓰던 부분을 통일했습니다. 그룹 영역은 내용이 넘치지 않게 확장됩니다.
- 자유 카드 드롭 종료 시 오래된 props 대신 최신 tasksRef를 사용합니다.
- 검증: 반복 삽입/제거, 큰 카드 포함 정렬, 음수 그룹 위치, 최소·최대 크기, 새로고침 복원, 그룹 삭제 시 표시 위치 유지.
