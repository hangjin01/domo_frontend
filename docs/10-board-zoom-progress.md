# 보드 확대·축소 작업 기록

## 요청
- Ctrl + 휠: 마우스 위치 중심 확대/축소(25–200%).
- 헤더/사이드바 크기는 유지. 배율 표시, 100% 복원, 전체 맞춤 제공.
- 확대 상태에서도 카드 이동/그룹 정렬/크기 변경/연결선 좌표 유지.
- 개발과 검증을 마친 뒤 Linux 앱을 마지막에 빌드.

## 2026-11-07 재개
- 기존 카드 크기/그룹 정렬 변경은 보존.
- 확대 기능 및 좌표 변환 구현 완료. Linux 최종 빌드 및 AppImage 패키징 성공.
- 검증: `env LD_LIBRARY_PATH=/usr/lib64 npm test`, `npx tsc --noEmit`.
